# Política de Segurança

## Relatando vulnerabilidades

Se você encontrar uma vulnerabilidade de segurança neste projeto, **não abra uma issue pública**.

Envie um e-mail para a pessoa responsável pelo repositório com os detalhes.

## Boas práticas

- Nenhum segredo, token ou chave de API está armazenado neste repositório
- O formulário de contato não envia dados para servidores — redireciona para o WhatsApp
- `rel="noopener noreferrer"` é usado em todos os links externos
- Variáveis de ambiente com prefixo `NEXT_PUBLIC_` não contêm informações sensíveis
- O site é 100% estático, sem banco de dados ou API Routes em produção
